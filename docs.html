Instalace jedním krokem

Ukažte agentovi cestu ke staženému balíčku (archiv .tar.gz nebo .zip) a vložte tuto větu — agent balíček rozbalí, spustí instalátor a nainstaluje se sám:

agent
Toto je stažený balíček legalsuite (legalsuite.tar.gz). Rozbal si ho a nainstaluj legalsuite podle přiloženého instalátoru (install.sh, na Windows install.ps1). Na prefix se mě zeptej a nic nepřepisuj bez zálohy.
